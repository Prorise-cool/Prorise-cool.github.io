5. 强大的 HTML5 API：赋能现代 Web 应用

HTML5 及其周边规范引入了许多强大的 JavaScript API，让 Web 应用能够执行以前只有桌面应用才能完成的任务。这些 API 极大地扩展了浏览器的能力。

我认为，这些 API 是 HTML5 作为应用平台的核心所在。掌握它们能够帮助我们构建更富交互性、更高效的 Web 应用。

5.1 Geolocation API：获取用户地理位置

Geolocation API 允许 Web 应用程序访问用户设备的地理位置信息（经度、纬度等）。用户需要明确授权才能分享位置信息，这是一个重要的安全和隐私特性。

方法/属性描述
navigator.geolocationGeolocation 对象的入口点。在使用前应检查此对象是否存在 (if (navigator.geolocation)).
getCurrentPosition(successCallback, errorCallback, options)获取用户当前位置。成功时调用 successCallback，失败时调用 errorCallback。options 参数可选。
watchPosition(successCallback, errorCallback, options)注册一个处理器，以便在用户位置发生变化时周期性地获取位置信息。返回一个 watchID。
clearWatch(watchID)停止监听用户位置变化。
Position 对象成功回调的参数，包含 coords (Coordinates 对象) 和 timestamp。
Coordinates 对象包含 latitude, longitude, altitude, accuracy, altitudeAccuracy, heading, speed 等。
PositionError 对象失败回调的参数，包含 code (错误码) 和 message。

使用场景: 地图应用、基于位置的服务、本地商家推荐等。

⚠️ 注意: Geolocation API 只能在安全的上下文 (HTTPS) 中使用，以保护用户隐私。

5.2 Web Storage API：客户端数据存储

Web Storage API 提供了一种比 Cookie 更简单、更安全、容量更大的客户端数据存储方式。它分为两种：localStorage 和 sessionStorage。

  • localStorage: 数据没有过期时间，除非用户清除浏览器缓存，否则数据一直存在。适用于长期存储不敏感的用户偏好设置、离线数据等。
  • sessionStorage: 数据只在当前会话（直到浏览器窗口关闭）有效。适用于存储用户在单次访问期间的状态信息，如购物车内容、表单输入草稿等。

它们都提供了一组相同的简单方法来存取键值对数据。键和值都必须是字符串。

方法/属性描述
setItem(key, value)存储键值对数据。如果键已存在，则更新其值。
getItem(key)根据键获取对应的值。如果键不存在，返回 null。
removeItem(key)根据键删除对应的键值对。
clear()清除所有存储的数据。
key(index)根据索引获取键名。
length获取存储数据的数量。

使用场景: 记住用户偏好（主题、语言）、存储购物车状态、离线应用数据、存储用户输入草稿等。

⚠️ 注意: Web Storage 是同步的，存储大量数据可能阻塞主线程。它只能存储字符串，对于对象和数组需要使用 JSON.stringify() 序列化和 JSON.parse() 反序列化。不要存储敏感信息，因为数据没有加密且容易通过客户端脚本访问。

5.3 Drag and Drop API：实现拖放交互

Drag and Drop API 允许用户使用鼠标（或触摸设备）拖动元素并在另一个位置释放它们，实现复杂的拖放交互。任何元素都可以设置为可拖动，其他区域可以设置为可放置目标。

拖放事件流程:

  1. 设置可拖动元素: 在元素上设置 draggable="true" 属性。
  2. 拖动开始: 元素被拖动时触发 dragstart 事件。可以在此事件中设置要传输的数据 (event.dataTransfer.setData())。
  3. 拖动过程:
    • 被拖动元素触发 drag 事件。
    • 当被拖动元素进入可放置目标区域时，目标区域触发 dragenter 事件。
    • 当被拖动元素在目标区域内移动时，目标区域触发 dragover 事件。注意: 必须阻止 dragover 事件的默认行为 (event.preventDefault())，否则元素无法被放置。
    • 当被拖动元素离开目标区域时，目标区域触发 dragleave 事件。
  4. 放置:
    • 当被拖动元素在目标区域释放时，目标区域触发 drop 事件。注意: 必须阻止 drop 事件的默认行为，并在事件中获取传输的数据 (event.dataTransfer.getData()) 并执行放置操作。
  5. 拖动结束: 拖动操作结束后（无论是否成功放置）触发 dragend 事件。可以根据 event.dataTransfer.dropEffect 属性判断操作结果。

dataTransfer 对象: 这是 Drag and Drop API 的核心，用于在拖动过程中存储和检索数据，以及设置拖动反馈（鼠标指针样式）。

方法/属性描述
setData(format, data)设置要传输的数据。format 是数据类型（如 'text/plain', 'text/html', 'Files' 等），data 是数据值。
getData(format)根据 format 获取传输的数据。
clearData(format)清除指定格式的数据。
effectAllowed设置拖动操作允许的效果 ('none', 'copy', 'link', 'move', 'copyLink', 'copyMove', 'linkMove', 'all')。
dropEffect获取当前放置目标的允许效果。在 dragover 和 drop 事件中设置，通常与 effectAllowed 配合使用。
files获取拖放操作中包含的文件列表 (FileList)。通常用于处理文件拖放上传。

简单拖放示例

读者可以看到，拖放功能依赖于事件的监听和 dataTransfer 对象的正确使用。这对于实现文件上传（通过 event.dataTransfer.files）、列表排序、可视化界面构建等场景非常有用。

5.4 Fetch API：现代异步网络请求

Fetch API 提供了一种更现代、更强大、更灵活的方式来发起网络请求，取代了传统的 XMLHttpRequest 对象。它基于 Promise，使得处理异步请求更加简洁。

概念/方法描述
fetch(url, options)发起网络请求的核心函数。url 是请求的资源 URL，options 是配置对象 (可选，用于设置方法、头部、请求体等)。返回一个 Promise，该 Promise 解析为 Response 对象。
Response 对象表示网络请求的响应。包含状态码 (status), 状态文本 (statusText), 头部信息 (headers), 是否成功 (ok), 是否重定向 (redirected), 以及用于解析响应体的方法。
Response.json()将响应体解析为 JSON。返回一个 Promise，解析为 JavaScript 对象。
Response.text()将响应体解析为文本。返回一个 Promise，解析为字符串。
Response.blob()将响应体解析为 Blob (二进制数据)。返回一个 Promise。
Response.arrayBuffer()将响应体解析为 ArrayBuffer。返回一个 Promise。
Response.formData()将响应体解析为 FormData。返回一个 Promise。
Request 对象表示网络请求。通常通过 new Request(url, options) 创建，然后作为 fetch 的第一个参数。
Headers 对象用于管理请求/响应的头部信息。可以通过 new Headers(init) 创建，然后用于 options.headers。

使用场景: AJAX 请求、与后端 API 交互、获取资源等。

Fetch API 的优点在于其简洁的语法、基于 Promise 的异步处理以及强大的可配置性。它是现代 Web 开发中进行网络通信的首选方式。

5.5 Web Workers API：在后台线程中运行脚本

Web Workers API 允许我们在独立的后台线程中运行 JavaScript 脚本，而不会阻塞主线程（UI 线程）。这对于执行耗时、计算密集型的任务（如处理大量数据、图像处理）非常有用，可以避免页面卡顿，保持用户界面的流畅。

Web Workers 与主线程之间的通信是通过消息传递 (postMessage()) 进行的。Worker 脚本无法直接访问 DOM 或全局的 window 对象。

概念/方法/属性描述
new Worker(scriptURL)创建一个新的 Worker 实例，并在指定的 scriptURL 加载并执行脚本。返回 Worker 对象。
worker.postMessage(message, transferList)向 Worker 线程发送消息。message 可以是任何可序列化的 JavaScript 对象。transferList (可选) 用于转移 ArrayBuffer 等的可转移对象。
worker.onmessageWorker 接收到主线程消息时触发的事件处理器。事件对象 (event) 的 data 属性包含接收到的消息。
worker.onerrorWorker 发生错误时触发的事件处理器。事件对象包含错误信息。
worker.terminate()立即终止 Worker 的执行。
self.postMessage(message, transferList)在 Worker 脚本内部，用于向主线程发送消息。self 指代 Worker 自身的全局作用域。
self.onmessage在 Worker 脚本内部，用于接收主线程发送的消息。

使用场景: 大文件处理、数据加密/解密、图像滤镜计算、复杂算法执行、大型游戏逻辑等。

5.6 其他重要 API (简述)

HTML5 及其后续规范还引入了许多其他有用的 API：

  • WebSockets API: 提供了在客户端和服务器之间建立持久性连接的能力，实现双向实时通信。适用于聊天应用、实时游戏、股票行情等。
  • Server-Sent Events (SSE) API: 允许服务器向客户端推送单向更新。适用于新闻推送、实时通知等（与 WebSocket 相比更轻量级，但只支持单向）。
  • Fullscreen API: 允许用户在全屏模式下观看特定元素（如视频播放器、游戏）。
  • Page Visibility API: 让开发者知道页面当前是否可见（在前景标签页）。可用于优化资源使用（如页面隐藏时暂停视频、动画或发送数据）。
  • History API: 提供了更友好的方式来操作浏览器会话历史（pushState, replaceState, popstate 事件），是实现单页应用 (SPA) 客户端路由的基础。
  • Web Components: 一套允许你创建可复用、封装好的自定义元素（包括 Custom Elements, Shadow DOM, HTML Templates）。有助于构建模块化和可维护的复杂 UI。
  • File API: 允许 Web 应用访问用户选择的本地文件，获取文件信息，读取文件内容（如图片预览、文本文件读取）。通常与 <input type="file"> 结合使用。
  • IndexedDB API: 提供了在客户端存储大量结构化数据的方式。是一个强大的客户端数据库，适用于离线应用等场景。

对于这些 API，读者可以根据自己的项目需求进一步深入学习。MDN Web Docs 是一个非常好的起点。
