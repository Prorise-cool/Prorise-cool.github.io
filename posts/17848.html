CSS 2D转换

在网页中原点是在左上角的位置

  1. X轴：这条轴通常表示水平方向。在主页上，X轴从左到右延伸。页面的左边通常有边栏或广告，中间是搜索框及搜索按钮，右边可能有用户的登录信息或其他功能链接。
  2. Y轴：这条轴代表垂直方向。在百度的页面上，Y轴从顶部到底部。顶部通常有logo和搜索框，中间部分可能展示搜索结果或其他用户互动区域，底部则是网站的脚注，包含版权信息、链接到法律信息或网站的其他部分。

简而言之，X轴控制页面的左右布局，而Y轴控制页面的上下布局。在首页上，你可以看到这两个轴如何定义内容和功能区域的布局，记住在控制布局的时候，给予X轴正值则是往左变动，给予Y轴赋值则是往右变动这个结论即可

1.transform：

  • 用途：对元素进行旋转、缩放、移动或倾斜等变换操作。
函数名称描述
translate(x,y)平移，指定 X 和 Y 坐标
translateX(x)沿 X 轴平移
translateY(y)沿 Y 轴平移
scale(x,y)缩放，指定 X 和 Y 比例
scaleX(x)X 轴缩放
scaleY(y)Y 轴缩放
rotate(angle)旋转，指定角度
skew(x-angle,y-angle)倾斜，指定 X 和 Y 轴角度
skewX(angle)X 轴倾斜
skewY(angle)Y 轴倾斜
matrix(a, b, c, d, e, f)应用 2D 变换矩阵
``应用 3D 变换矩阵

2.transition：

  • 用途：实现元素在状态改变时的平滑过渡效果，可以定义过渡时间、类型和延迟。

  • 方法：

    属性描述
    transition-property过渡属性名称，宽/高`
    transition-duration过渡持续时间，如 2s
    transition-timing-function过渡时的速度曲线，如 ease-in
    transition-delay过渡开始前的延迟，如 1s
    复合写法：transition:all 1s ease-in 0s;定义所有属性变化的过渡效果

3.transition-timing-function：

  • 用途：指定过渡效果的时间函数，控制过渡效果的速度和形式。
  1. 预定义的速度曲线：
    • ease - 开始时速度较慢，然后加快，在结束前变慢。
    • linear - 动画从头到尾的速度是相同的。
    • ease-in - 动画以慢速开始。
    • ease-out - 动画以慢速结束。
    • ease-in-out - 动画以慢速开始和结束。
  2. 阶梯函数：
    • steps(int,start|end) - 允许你定义一个动画为几个离散的步骤。例如，steps(4, end) 将确保动画分为四个步骤完成，每个步骤都是突然跳变的。
  3. 贝塞尔曲线：
    • cubic-bezier(n,n,n,n) - 允许你定义一个自定义的贝塞尔曲线，通过四个值控制其形状，其中每个 n 代表一个坐标点。例如，cubic-bezier(0.42, 0, 0.58, 1) 产生一个与 ease-in-out 类似的效果

4.transform-origin：

  • 用途：指定元素变换的原点，控制元素进行变换时的基准点。

5.animation：

利用 transition 属性可以实现简单的过渡动画，但过渡动画仅能指定开始和结束两个状态，整个过程都是由特定的函数来控制的，不是很灵活。本节我们再来介绍一种更为复杂的动画 —— animation。

属性名描述默认值
animation-name指定要应用的动画的名称。none
animation-duration指定动画的持续时间。0s
animation-timing-function指定动画的时间函数。ease
animation-delay指定动画开始之前的延迟时间。0s
animation-iteration-count指定动画的播放次数。1
animation-direction指定动画在播放期间是否反向播放。normal
animation-fill-mode指定动画的填充模式。none
animation-play-state指定动画的播放状态。running

1.animation-name

animation-name 属性用来将动画绑定到指定的 HTML 元素，属性的可选值如下：

值描述
keyframename要绑定到 HTML 元素的动画名称，可以同时绑定多个动画，动画名称之间使用逗号进行分隔
none表示无动画效果，

注意：要想让动画成功播放，您还需要定义 animation-duration 属性，否则会因为 animation-duration 属性的默认值为 0，导致动画并不会播放。

2.animation-timing-function

animation-timing-function 属性用来设置动画播放的速度曲线，通过速度曲线的设置可以使动画播放的更为平滑。animation-timing-function 属性的可选值如下表所示：

值描述
linear动画从开始到结束的速度是相同的
ease默认值，动画以低速开始，然后加快，在结束前变慢
ease-in动画以低速开始
ease-out动画以低速结束
ease–in-out动画以低速开始，并以低速结束
cubic-bezier(n, n, n, n)使用 cubic-bezier() 函数来定义动画的播放速度，参数的取值范围为 0 到 1 之间的数值

3.animation-fill-mode

animation-fill-mode 属性用来设置当动画不播放时（开始播放之前或播放结束之后）动画的状态（样式），属性的可选值如下：

值描述
none不改变动画的默认行为
forwards当动画播放完成后，保持动画最后一个关键帧中的样式
backwards在 animation-delay 所指定的时间段内，应用动画第一个关键帧中的样式
both同时遵循 forwards 和 backwards 的规则
