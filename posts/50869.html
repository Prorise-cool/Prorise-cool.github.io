浮动

浮动可以使一个元素脱离自己原本的位置，并在父元素的内容区中向左或向右移动，直到碰到父元素内容区的边界或者其它浮动元素为止。

值描述
left元素向左浮动
right元素向右浮动

另外，在使用 float 属性时还需要注意以下几点：

  • 当元素设置了绝对定位或者 display 属性的值为 none 时，float 属性无效；
  • 相邻的浮动元素，如果空间足够它们会紧挨在一起，排列成一行。

清除浮动

元素浮动之后，会对周围的元素造成一定的影响，为了消除这种影响您可以使用 clear 属性来清除浮动，属性的可选值如下：

值描述
left左侧不允许浮动元素
right右侧不允许浮动元素
both左右两侧均不允许浮动元素
none默认值，允许浮动元素出现在左右两侧
inherit从父元素继承 clear 属性的值

  • 从左开始排列
  • 一个块元素占一行

解决方法三：伪类法①

  1. .clearfix:after: 这个伪元素被插入到 .clearfix 元素的子元素内容之后。换句话说，它会出现在 .clearfix 元素的最后一个子元素之后。

  1. .clearfix:

定位

定位postion属性，可以让我们将元素从文档流中取出，然后使用方位词属性（left top right bottom）精准的控制它的位置。

不同的定位值可以使元素拥有不同的表现形式，例如放在另外一个元素上面或者固定在浏览器的显示区某个位置。

取值说明
static默认值，静态定位，表示没有定位，元素会按照正常的位置显示，此时 top、bottom、left 和 right 4 个定位属性也不会被应用。
relative相对定位，即相对于元素的正常位置进行定位，您可以通过 top、right、bottom、left 这 4 个属性来设置元素相对于正常位置的偏移量，在此过程中不会对其它元素造成影响。
absolute绝对定位，相对于第一个非 static 定位的父级元素进行定位，可以通过 top、right、bottom、left 这 4 个属性来设置元素相对于父级元素位置的偏移量。如果没有满足条件的父级元素，则会相对于浏览器窗口来进行定位。使用绝对定位的元素不会对其它元素造成影响。
fixed固定定位，相对于浏览器的创建进行定位，可以使用 top、right、bottom、left 这 4 个属性来定义元素相对于浏览器窗口的位置。使用固定定位的元素无论如何滚动浏览器窗口元素的位置都是固定不变的。
sticky粘性定位，它是 relative 和 fixed 的结合体，能够实线类似吸附的效果，当滚动页面时它的效果与 relative 相同，当要滚动到屏幕之外时则会自动变成 fixed 的效果。

1. relative

相对定位能让元素保持原文本流位置的同时，可以通过方位属性进行相对于原位置的偏移。

  • 不会脱离文档流
  • 不影响元素本身的任何特性
  • 如果不加方位词偏移那么没有任何影响
  • 适合小范围移动

2. absolute

绝对定位能让元素脱离文档流（原地起飞…），使用方位属性相对于父级元素进行偏移

方位属性left和top 优先级比 right和bottom高，比如一个元素既拥有left也拥有right，最终位置以left为准。

  • 脱离文档流

  • 元素宽高默认值为0

  • 找不到最近的定位父级则相对于body标签

  • 一般配合相对定位使用（参照物）

  • 会将元素转换成块元素

  • 设置了绝对定位,没有设置层级;html后写居上

  • margin:auto 暂时失效

3. fixed

固定定位能让元素脱离文档流，使用方位属性相对于浏览器可视区进行偏移；

  • 脱离文档流
  • 元素宽高默认值为0
  • margin:auto失效

4. 粘性定位：sticky

它像是相对定位和固定定位的结合体，当滚动页面时它的效果与相对定位相同，当元素滚动到一定程度时它又会呈现出固定定位的效果，比如一些网页上的导航菜单，当页面加载完成时它在自己默认的位置，当我们向下滚动页面时它又会固定在页面的最顶端。

在使用粘性定位时，需要注意以下几点：

  • 在设置position:sticky;时，必须再定义 top、bottom、right、left 四个属性之一，否则只会处于相对定位的状态；
  • 使用粘性定位元素的父元素不能定义overflow:hidden或者overflow:auto属性；
  • 父元素的高度不能低于粘性定位元素的高度；
  • 粘性定位的元素仅在其父元素内有效。

5. 层级

定位元素之间，如果出现覆盖问题，那么越到后面的元素优先级越高，当然我们可以使用z-index层级属性来调整优先级。数值越大，越靠上。

z-index属性只针对定位元素有效

取值为一个整数数字，默认auto 或 0 ，可正可负

Flex布局

2.1 基本概念

采用Flex布局的元素，称为Flex容器（flex container），简称“容器”。它的所有子元素自动成为容器成员，称为Flex项目（flex item），简称“项目”。容器默认存在两根轴，分别为水平的主轴（main axis）和垂直的交叉轴（cross axis）。主轴的开始位置叫做 main start，结束位置叫做 main end；交叉轴的开始位置叫做 cross start，结束位置叫做 cross end。项目默认沿主轴排列。单个项目占据的主轴空间叫做 main size，占据的交叉轴空间叫做 cross size。

简而言之，Flex布局是一种在容器中排列子元素的方式，其中子元素默认沿主轴排列，并可以在主轴和交叉轴上占据不同的空间，起始点X默认在左，起始点Y默认在上

  • 主轴：Flex项目排列的方向，默认情况下是水平方向（即row）。你可以使用flex-direction属性来改变主轴的方向，例如设置为row-reverse、column或column-reverse。
  • 辅轴：这是与主轴垂直的方向。当主轴是水平方向时，辅轴就是垂直方向；当主轴是垂直方向时，辅轴就是水平方向。辅轴的方向并不是通过直接设置属性来改变的，而是通过改变主轴的方向来间接确定的。

**如何使用：**通过将元素的 display 属性设置为 flex（生成块级 flex 容器），Flex容器的所有子元素自动成为容器成员，我们称为Flex项目。

2.2 Flex容器属性

**flex-direction：**决定主轴的方向（即项目的排列方向）

值描述
row默认值，水平主轴，从左往右
row-reverse水平主轴，从右往左
column垂直主轴，从上到下
column-reverse垂直主轴，从下到上

**flex-wrap：**决定子元素主轴摆放不下的时候，项目换不换行，默认不换行。

值描述
nowrap默认值，不换行；（摆放不下按比例缩放）
wrap表示项目会在需要时换行
wrap-reverse表示项目会在需要时换行，但会以相反的顺序

flex-flow：flex-flow 属性是 flex-direction 和 flex-wrap 两个属性的简写，语法格式如下：

默认值为flex-flow: row nowrap;

**justify-content：**用于设置弹性盒子中元素在主轴（横轴）方向上的对齐方式，属性的可选值如下

值描述
flex-start默认值，起点对齐；
flex-end终点对齐；
center居中
space-between两端对齐，中间间隔分均分配；
space-around所有子元素拥有相同的左右(上下)间隔
space-evenly所有间隔平均分均

**align-items：**用来设置弹性盒子中元素在侧轴（纵轴）方向上的对齐方式，属性的可选值如下：

  • flex-start，上对齐；
  • flex-end，下对齐；
  • center，居中；
  • baseline，可以让不同行的文本在底部对齐
  • stretch，默认值，继承父盒子的高度（如果全部子元素都有设置高度值，则表现和flex-start一致。）

**align-content：**定义多主轴之间（也就是换行后行与行之间）的对齐方式。所以，如果子元素没有换行，这个属性就不起作用。

  • flex-start，副轴起点对齐；
  • flex-end，副轴终点对齐；
  • center，副轴居中对齐；
  • space-between，副轴两端对齐，中间平均分配；
  • space-around，每行之间间距平均分配；
  • space-evenly 所有间隔平均分均

2.3 Flex项目属性

**order：**Flex项目的展示顺序，值为一个数字，越小越优先摆放。

**flex-grow：**规定主轴有剩余空间时 子元素增大的分配比例，默认为0，即不增大。

**flex-shrink：**规定主轴空间不足时 子元素缩小的分配比例，默认为1，即分均分配来缩小。

**align-self：**允许子元素自己规定自己的对齐方式。该属性默认继承父级的align-items，可以通过修改各自的align-self实现各个子元素不同的对齐方式。

flex-basis:指定元素在主轴方向上的初始尺寸的属性，它定义元素在没有伸缩空间时的尺寸。

flex:简写属性:内部顺序如下：

  1. flex-grow
  2. flex-shrink
  3. flex-basis

2.4圣杯布局

grid布局

又称作网格布局，它把网页划分成一个一个网格，也是最强大的布局

Flex轴线布局只能够指定“项目”针对轴线的位置，可以看作是一维布局

grid网格布局则是将容器划分成“行”和“列”，产生单元格来设定“项目”所占空间，可以看作是二维布局

更理想的状况是，两种布局可以协同工作

2.1 基本概念

我们将网格布局称为容器，容器内部采用网格定位的直接子元素称之为项目

容器里的水平区域称之为行、垂直区域称为列，行和列组成的小方块称之为单元格、划分网格的线分为网格线

垂直的网格线称之为列网格线、水平的网格线称之为行网格线，两格网格线相邻的空间称为网格轨道，任意一个或者多个连成的单元格称之为区域。

2.2 Grid容器属性

属性描述
display: grid;将元素定义为网格容器，启用网格布局。
grid-template-columns定义网格布局中列的大小和数量。可以指定固定长度、百分比、fr 单位等。
grid-template-rows定义网格布局中行的大小和数量。同样可以指定固定长度、百分比、fr 单位等。
grid-template-areas定义网格布局中的区域模板，指定每个区域的名称和排列方式。
grid-template简写属性，同时定义 grid-template-columns、grid-template-rows 和 grid-template-areas，一次性定义网格的结构和区域模板。

这些属性用于控制自动布局中未显式定义的网格行和列的特性。

Grid-auto-flow

决定项目的排序顺序，默认值为row，即“先行后列”、可以修改为column变成“先列后行”

语法：

参数解释：

  • row：默认值。网格项按照先行后列的顺序摆放，即先填充每一行，再从上到下逐列填充。
  • column：网格项按照先列后行的顺序摆放，即先填充每一列，再从左到右逐行填充。

Grid-auto-colums/row

当使用 CSS Grid 布局时，有时候我们可能无法事先确定网格容器中的所有行和列的数量，或者希望让一些网格项自动填充未被显式定义的行和列。这时就可以使用 grid-auto-rows 和 grid-auto-columns 这两个属性来定义自动布局中未显式定义的行和列的大小。

grid-auto-columns 是 CSS Grid 布局中用于定义自动布局中未显式定义的列的大小的属性。它可以接受多种不同的值来设置未定义列的大小和样式，而grid-auto-row也是同理的

以下是 grid-auto-columns 可以接受的主要值：

  1. 固定长度值（Fixed Length）：可以直接指定固定的像素值或其他长度单位作为列的宽度。

  2. 百分比值（Percentage）：可以指定相对于父容器宽度的百分比作为列的宽度。

  3. fr 单位值（Flexible Length）：可以使用 fr 单位设置自动分配剩余空间的列宽。

  4. 最小内容值（Min Content）：可以根据列内容的最小宽度来确定列的宽度。

  5. 最大内容值（Max Content）：可以根据列内容的最大宽度来确定列的宽度。

  6. 适应内容值（Fit Content）：可以根据内容的适应宽度来确定列的宽度。

响应式布局

2010年前后，移动端设备快速发展，同一个网页如何在不同分辨率下的设备都能够正常的显示出来，成为一个非常现实的问题，这个时候有人提出了自适应布局的概念

自适应布局：在不同分辨率的终端设备上，网页自动调整元素尺寸，显示出相同的视觉效果

使用场景：网页结构和内容相对复杂的情况

而要解决这个问题需要思考两点：

  • ①根据浏览器宽度调整网页整体的缩放比例（视口）
  • width=device-width：指定视口宽度等于设备的宽度，确保在不同设备上显示的内容尺寸一致。
  • user-scalable=no：禁止用户缩放页面，防止用户通过手势放大或缩小页面。
  • initial-scale=1.0：初始缩放比例为 1.0，即默认情况下页面不进行缩放。
  • maximum-scale=1.0：最大缩放比例为 1.0，限制用户无法放大页面。
  • minimum-scale=1.0：最小缩放比例为 1.0，限制用户无法缩小页面。

这些设置可以确保在移动设备上显示的页面具有良好的可视性和用户体验，同时限制了用户对页面的缩放操作，以保持设计的一致性和稳定性。

  • ②根据分辨率调整内容的显示效果

    • rem布局：等比缩放布局。

      不同设备看起来比较协调，但显示的内容比较少

      规则：① 一般不给元素设置具体的宽度（小图标除外）

    • 流式布局：百分比布局，也就是flex弹性布局

      大屏幕下显示更多的内容，但宽屏下比例不协调

      原则：① 文字流式：文字大小不变，显示宽度改变
