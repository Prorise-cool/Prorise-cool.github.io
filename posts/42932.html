CSS 字体与文本样式

1. 字体样式

字体设置也是网页设计中的重要组成部分，合适的字体不仅会使页面更加美观，也可以提升用户体验。CSS 中提供了一系列用于设置文本字体样式的属性，比如更改字体，控制字体大小和粗细等等。

1.1 继承性

大部分的字体和文本属性我们只需要给父元素加子元素也会生效。有这样的特点的存在好处就是可以减少代码。给父元素加子元素就有了。如果元素有默认样式，此时继承性依然存在，但是优先显示默认样式。

a标签的color会继承失效：其实color属性继承下来了，但是被浏览器默认设置的样式给覆盖掉了

1.2 font-size

font-size 属性用来设置字体的大小， 默认16px最小值12px ，0px字体不显示。

  • % 相对于父级字体大小
  • em 1em 父级字体大小
  • rem 1rem html标签字体大小(默认16px) (常用在移动端适配)

1.3 font-weight

font-weight 属性能够设置字体的粗细，可选值如下：

值描述
normal默认值，标准字体
bold粗体字体
bolder更粗的字体
lighter更细的字体
100、200、300、400、500、600、700、800、900由细到粗的设置字体粗细，100 为最细的字体，400 等同于 normal，700 等同于 bold

1.4 font-family

font-family 属性用来设置元素内文本的字体。由于字体的种类成千上万，而且有些还不是免费的，因此我们的电脑上几乎不可能拥有所有的字体。为了最大程度的保证我们设置的字体能够正常显示，可以通过 font-family 属性定义一个由若干字体名称组成的列表，字体名称之间使用逗号,分隔，浏览器会首先尝试列表中的第一个字体，如果不支持则尝试下一个，以此类推。

1.5 line-height

行高控制每一行文字的高度，文字会在这个行高内垂直居中显示。

当我们给文本设置字体大小，会按照字体大小的1.32这个比例给文字设置行高

行高（line-height） = 文字大小（font-size） + 上下的行间距（两个文字之间的距离就是上下行间距）

垂直居中技巧: 设置行高属性值 = 自身高度属性值

  • px：外部盒子没有设置固定高度 line-height可以撑高外部盒子
  • em：相对于元素本身的字体大小 em可以省略 如 1.5em 省略为=> 1.5
  • rem：html标签的字体大小

1.6 font-style

font-style 属性用来设置字体的样式，例如斜体、倾斜等，该属性的可选值如下：

值描述
normal默认值，文本以正常字体显示
italic文本以斜体显示
oblique文本以倾斜显示
inherit从父元素继承 font-style 属性的值
<angle>可以使用角度值来指定斜体的角度，但在实践中较少使用

2. 文本样式

通过 CSS 中的文本属性您可以像操作 Word 文档那样定义网页中文本的字符间距、对齐方式、缩进等等

2.1 text-align

text-align 属性用来设置元素中文本的水平对齐方式，属性的可选值如下：

值描述
left默认值，左对齐
right右对齐
center居中对齐
justify两端对齐

当text-align 设置为 justify 时，将拉伸每一行文本（增加字符之间的间距），以使每行文本具有相同的宽度（最后一行除外），这种对齐方式通常用于出版物，例如杂志和报纸。需要特别注意的是，如果元素中的文本不足一行时，是无法实现两端对齐的（默认会以左对齐的效果显示）。只有当元素中的文本足够长，并且在元素中发生了自动换行时，才会将除最后一行以外的文本实现两端对齐。

2.2 text-indent

text-indent 属性用来为元素中的文本添加首行缩进的效果，属性的可选值如下：

值描述
length以固定的值加单位的形式（例如 2em）定义缩进距离，默认值为 0
%以基于父元素宽度的百分比来定义缩进距离

2.3 text-decoration

text-decoration 属性用于设置或删除文本的装饰，最常用的做法就是使用 text-decoration 属性来删除<a>标签的默认下划线。当然了，使用 text-decoration 属性也可以在需要的地方为元素中的文本添加一些装饰，达到突出显示的效果。

值描述
none默认值，标准文本，没有额外装饰，可以用来删除已有的文本装饰
underline在文本下方添加一条下滑线
overline在文本上方添加一条上滑线
line-through在文本的中间定义一条横向贯穿文本的线（类似于删除线）
blink文本闪烁
inherit继承父元素的装饰效果
initial设置为默认的装饰效果
unset重置为默认的装饰效果

2.4 letter-spacing

letter-spacing属性用来设置识别单个字母或者文字的间距。属性的可选值如下：

值描述
normal默认值，表示字符之间没有额外的间距
length以数值加单位的形式设置字符之间的固定间距

2.5 文本溢出显示

换行方式 (white-space)

  • normal：默认值，正常换行
  • nowrap：文本不换行

溢出行为 (overflow)

  • visible：默认值，溢出的内容会呈现在框外面
  • hidden：溢出的内容会被裁剪，隐藏不显示

文本溢出显示方式 (text-overflow)

  • ellipsis：在文本溢出时显示省略号。
  • clip：默认值，溢出的文本被裁剪，隐藏不显示。

用户选择方式 (user-select)

  • none：用户无法选中元素中的文本。

  • auto：默认值，允许用户选择元素中的文本。

  • text：允许用户选择元素中的文本，这是 auto 的一个别名。

2.6 vertical-align

vertical-align 属性控制行内元素在其所在行中的垂直位置。这个属性不是说元素本身的垂直位置，而是指定了元素内部文本的对齐方式。

  1. 行内元素：行内元素是指在文档流中水平排列的元素，比如 <span>、<a>、<strong> 等。它们不会单独占据一行，而是在同一行内按照它们的大小和内容水平排列。
  2. 基线：基线是行内文本底部的水平线，通常用于对齐行内元素。比如，字母的底部就是基线。

每行文字都有一个基线，它是文字底部的水平线。vertical-align 属性就是告诉浏览器，元素的基线（也就是文字的基线）应该和所在行的基线相对齐到什么位置。
以下是 vertical-align 属性的可选值列表：

值描述
baseline元素的基线与父元素的基线对齐。
top元素的顶部与父元素的顶部对齐。
middle元素的中部与父元素的基线的中部对齐。
bottom元素的底部与父元素的底部对齐。
text-top元素的顶部与父元素的文本字体的顶部对齐。
text-bottom元素的底部与父元素的文本字体的底部对齐。
<length>使用像素、点数或其他长度单位指定对齐的偏移量。
<percentage>使用百分比指定对齐的偏移量。
sub元素相对于基线下移，通常用于下标。
super元素相对于基线上移，通常用于上标。
inherit继承父元素的 vertical-align 属性值。
