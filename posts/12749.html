三、面向对象

1、面向对象概述

面向对象和面向过程的区别

面向过程：

优点：性能比面向对象高，因为类调用时需要实例化，开销比较大，比较消耗资源;比如单片机、嵌入式开发、Linux/Unix等一般采用面向过程开发，性能是最重要的因素。

缺点：没有面向对象易维护、易复用、易扩展

面向对象：

优点：易维护、易复用、易扩展，由于面向对象有封装、继承、多态性的特性，可以设计出低耦合的系统，使系统更加灵活、更加易于维护

缺点：性能比面向过程低

面向过程是具体化的，流程化的，解决一个问题，你需要一步一步的分析，一步一步的实现。

面向对象是模型化的，你只需抽象出一个类，这是一个封闭的盒子，在这里你拥有数据也拥有解决问题的方法。需要什么功能直接使用就可以了，不必去一步一步的实现，至于这个功能是如何实现的，管我们什么事？我们会用就可以了。

面向对象的底层其实还是面向过程，把面向过程抽象成类，然后封装，方便我们使用的就是面向对象了。

10 继承的定义和使用

继承的本质：在原有类的基础上继续进行扩充。

子类又称作派生类，父类称作 superClass。

  • 使用 extends 关键字来定义继承关系。

10.1 子类对象实例化流程

  • super() 表示子类构造调用父类构造的方法，该语句必须在子类构造方法的第一行。
  • 默认情况下，子类会调用父类的无参构造，但如果父类没有无参构造
  • 实例化子类对象时，必然会先实例化父类对象，这样可以为所有继承的属性分配内存空间。
  • this 用于调用本类构造方法，super 用于调用父类构造方法，两者都必须在第一行，不能同时出现。

10.2 继承定义限制

  1. Java 不支持多重继承，只允许多层继承：一个类不能同时继承多个类，但可以形成继承链（即 A → B → C）。
  2. 子类可以继承父类的所有成员（字段和方法），但：
    • private 修饰的成员是隐式继承，子类无法直接访问，但仍然存在于子类对象中。
    • 其他 public、protected、默认（包访问权限）的成员属于显式继承，子类可以直接使用或重写。
  3. 隐式继承（private 成员）：
    • 子类继承了父类的 private 成员，但由于访问控制的限制，子类无法直接访问这些成员。
    • 可以通过提供 getter/setter 方法，让子类间接访问父类的 private 属性。

10.5 方法重写（Override）

在继承关系中，子类可以重写（Override）父类的方法，以提供不同的实现。

方法重写的规则：

  1. 方法名和参数列表必须完全一致。
  2. 返回值必须相同（JDK1.5+ 允许返回子类类型的值）。
  3. 不能降低父类方法的访问权限（public > protected > default > private）。
  4. final 修饰的方法不能被重写。
  5. static 方法不能被重写（但可以在子类中重新定义一个相同名称的方法）。

super 的三种用途：

  1. 调用父类的构造方法（必须放在子类构造方法的第一行）。
  2. 访问父类的成员变量（当子类中有同名变量时，super 可区分）。

16 多态性

16.1 多态性简介

多态（Polymorphism） 是指同一个接口、方法或者对象，在不同的情况下表现出不同的行为。
在 Java 中，多态主要体现在两方面：

  1. 方法的多态：

    • 方法重载（Overloading）：同一个类中，方法名相同但参数不同（个数、类型不同）。
    • 方法覆写（Overriding）：子类重写父类方法，提供自己的实现。

  2. 对象的多态性（重点）：

    • 向上转型（Upcasting）：子类对象赋值给父类引用。
    • 向下转型（Downcasting）：父类引用转换回子类对象（必须先向上转型）。

为什么使用多态？

  1. 代码更加灵活：
    • 通过父类引用操作子类对象，可以方便地切换不同的子类，而不需要修改方法定义。。
  2. 提高扩展性：
    • 新增子类时，不需要修改原有代码，只需继承并覆写父类方法即可。
  3. 符合面向对象的设计思想：
    • 父类定义通用行为，子类实现具体细节，符合**“开闭原则”（对扩展开放，对修改封闭）**。

16.2 对象向上转型

向上转型指的是：子类对象赋值给父类引用，自动完成转换。
优势：可以使用父类统一管理所有子类对象，而不需要分别声明多个子类类型的变量。

示例：向上转型

解释：

  • Student 和 Teacher 继承 Person，并 覆写了 print() 方法。
  • fun(Person person) 接受 Person 类型的参数，但是运行时调用的是子类的方法，实现多态性。
  • 向上转型的核心：变量的类型是父类，但调用的是子类的方法。

16.3 对象向下转型

向下转型是指 将父类引用强制转换为子类引用，以便访问子类特有的方法。
⚠ 重要：向下转型 必须在对象先向上转型后，才能安全转换，否则会引发 ClassCastException。

29 bean规范

1. 类必须是公共的（public）

  • Java Bean必须是一个公共的类，允许它在其他类中被访问。

2. 必须有一个无参构造函数（No-arg Constructor）

  • 类应该有一个默认的无参构造函数，这样可以便于框架和库进行实例化。

3. 属性必须私有（Private Fields）

  • 属性应该是私有的，以确保封装性。通过公共的 getter 和 setter 方法访问。

4. 提供 getter 和 setter 方法

  • Getter方法：用于获取属性的值，命名规则是get后跟属性名（首字母大写），例如getName()。
  • Setter方法：用于设置属性的值，命名规则是set后跟属性名（首字母大写），例如setName(String name)。

5. 遵循命名规范

  • 属性命名：一般采用驼峰命名法（camel case），例如firstName。
  • getter方法命名：get属性名，例如getFirstName()。
  • setter方法命名：set属性名，例如setFirstName(String firstName)。

6. 可序列化（Serializable）

  • 如果需要将Java Bean实例进行序列化（例如传输或持久化），类应该实现Serializable接口。

在Java中，序列化是通过实现Serializable接口来实现的。这个接口是一个标记接口，不包含任何方法，只用于告诉JVM该类的对象可以被序列化

7. 有意义的字段

  • Java Bean类应该用于封装数据，字段应该有明确的意义，而不是任意的公共变量。
