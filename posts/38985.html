四、IO流

I/O 流（Input/Output Streams）是 Java 用于处理数据输入和输出的工具。I/O 操作允许程序读取外部数据（如文件、控制台、网络）并将数据写入外部资源。

  • I 是 Input（输入）：数据从外部读取到内存。
  • O 是 Output（输出）：数据从内存写入到外部。

Java I/O 包 java.io.* 提供了 四大家族 进行数据读写：

类型读（输入流）写（输出流）
字节流InputStream（抽象类）OutputStream（抽象类）
字符流Reader（抽象类）Writer（抽象类）

4. 常用 Java I/O 流 API

字节(byte)是数据存储的最小单位(8位)，字符(char)是显示的最小单位(如’A’、’中’等可见符号)。

4.1 字节流

4.1.1 文件字节输入流 FileInputStream

作用：从文件读取字节数据。

4.2 字符流

4.2.1 文件字符输入流 FileReader

作用：从文件中读取字符数据。

4.2.2 文件字符输出流 FileWriter

作用：向文件写入字符数据。

4.3 缓冲流（提高性能）

BufferedReader & BufferedWriter 用于高效读取/写入文本数据。

4.3.1 BufferedReader（带缓冲的字符输入流）

4.3.2 BufferedWriter（带缓冲的字符输出流）

4.4 对象流（序列化 & 反序列化）

对象流的作用：
在 Java 中，对象不能直接存储到文件中或通过网络传输，需要将对象转换为 字节流 才能存储或传输。
Java 提供了 ObjectOutputStream（对象输出流） 和 ObjectInputStream（对象输入流） 来实现 序列化（Serialization） 和 反序列化（Deserialization）。

4.4.1 ObjectOutputStream（对象序列化）

（作用：把 Java 对象保存到文件中，以后可以恢复）

📌 代码解析

  1. Person 类必须实现 Serializable 接口，否则不能序列化（Java 规定）。
  2. 使用 ObjectOutputStream 可以将 Person 对象写入 "person.ser" 文件。
  3. writeObject() 方法用于 将对象转换为字节流 并存储到文件中。
  4. 存储的文件 不是普通文本，而是二进制格式的 对象数据。

4.4.2 ObjectInputStream（对象反序列化）

（作用：从文件中读取对象，恢复为 Java 对象）
